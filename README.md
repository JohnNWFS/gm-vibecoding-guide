# GameMaker LLM Vibecoding Guide

Shared guidance for using Codex, Claude Code, ChatGPT, and other LLM coding
agents on GameMaker Studio / GML projects.

Start here:

project's own docs, and add only broadly reusable GameMaker/GML lessons here.
